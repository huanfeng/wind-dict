# 在线词典是并列的词典，不是离线的兜底

词典以 tab 并列呈现，在线词典是其中之一。离线未命中时，界面**提示**用户可切换到在线词典，但**绝不自动发起在线查询**。查询词全局共享，切换 tab 只改变由哪个词典来解释它；切到在线 tab 即视为用户的明确意图，立即发起请求并在会话内缓存结果。

## 为什么不做自动兜底

自动兜底看起来严格更优，因此这个决定必须记下来，否则它一定会被「修复」。拒绝它的理由有三条，每条独立成立：

1. **配额**。免费词典 API 的额度经不起「每次未命中都自动请求」。而未命中恰恰高频发生于用户拼错词、输入到一半、或查的根本不是英文——这些场景自动请求的价值为零，却照样烧配额。
2. **隐私**。自动兜底意味着用户打进输入框的任何东西，只要离线不认识，就会被静默发往第三方。用户从未同意过这件事。作为一个常驻后台、可被热键随时唤起的工具，这个默认行为是不可接受的。
3. **可降级**。在线词典既然是一个并列的词典而非管线中的一环，就可以被整个关掉、替换或增加，而不触及离线查询路径。兜底模型会把在线耦合进查询主路径。

## 后果

- 未命中时用户需多一次点击才能看到在线结果。这是**刻意付出的代价**，换取上述三条。
- 「在线查询失败/超时」的错误只影响在线 tab 内部，永远不会影响离线查询的呈现。
- 新增词典（如日汉、专业词典）是加一个 tab，不需要修改任何既有词典的逻辑。
