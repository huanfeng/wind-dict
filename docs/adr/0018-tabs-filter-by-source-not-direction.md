# 结果区的页签按来源分，不按方向分

右栏那排页签从「全部 / 英汉 / 汉英」改成「全部 / 每一本词典各一个」，内置的两份
词库也各占一个。本次没命中的页签**置灰留在原位**，不摘掉。

## 方向这个轴在单次查询里没有区分力

方向由查询词推出（ADR-0003）：查 `hello` 走英汉，查 `你好` 走汉英。于是对**任何
一次查询**，那两页必然是「一页有货、一页空着」——用户点进空的那一页，看到的永远
是「本次查询没有汉英方向的词条」。

一个恒为空的页签不是筛选器，是噪音。它们从来没挣到自己的位置，只是在自带词典进来
之前，那是仅有的可切的东西。

有区分力的是**来源**：查 `hello` 时内置英汉库与自带的那本各给一段释义，用户真正
会问的是「另一本怎么说」。

## 一条词条属于哪一页

内置两份靠**词条类型**认：`Entry::English` 只可能来自 ECDICT，`Entry::Chinese`
只可能来自 CC-CEDICT——这不是猜，是 `OfflineDictionary::lookup` 按方向选路的直接
结果。自带词典靠**稳定键**（文件名）认，不能靠显示名：两个文件的 MDX 标题一模一样
是常有的事，而且用户随时能改名，拿名字当依据会把两本的词条混进同一页。

**逐条筛，不是整张卡片筛。** 一个词头下面常常同时挂着内置词库与自带词典的词条
（查 hello 就是）：整张留下，点进「简明英汉字典」还看得见另一本的内容，页签名就是
在撒谎；整张丢掉，这个词头会从它确实收录的那一页里消失。筛空的卡片整张丢掉——
只剩一个词头、底下什么都没有的卡片没有信息量。

## 没命中的置灰，不摘掉

摘掉的话，每查一个词后面所有页签就整体左移一格，看着像换了一条标签条，而「总是点
第三个」这条肌肉记忆当场作废。置灰则位置恒定，且一眼能看出「这本这次没有」——那
本身就是有用的信息。

为此给 windui 的 `TabItem` 补了逐项 `enabled(Signal<bool>)`（此前只有整条标签条的
禁用态）。**收信号而非布尔**：可用与否每查一次就变，而页签集合只在装卸词典或改名
时才变；收布尔就意味着结果一变就要重建整条标签条，而重建会丢掉悬停态、并让选中
滑块从头落定而不是滑过去。

一条结果都没有时**全部保持可用**：那是「还没查」或「这个词没收录」，不是「这本
词典没有它」。全灰会让开屏那一眼看着像所有词典都坏了。

## 名字：默认给中文，且用户可以改

页签要有名字，而**「英汉」不是名字，是方向**——两本不同的英汉词典都叫「英汉」，
用户无从区分。内置两份的默认名取中文：

| 键 | 默认名 | 出处 |
|---|---|---|
| `ecdict` | 简明英汉字典 | ECDICT 的中文正名，上游自己这么叫 |
| `cedict` | 汉英词典 | CC-CEDICT **没有**中文正名，这是个描述性名字 |

CC-CEDICT 就叫 CC-CEDICT，那是专名不是缩写词，对中文用户不友好；这里给一个说得通
的名字，并让用户能改。改名存在 `Settings::dict_names`，按**稳定键**存——内置那两份
的键是 `ecdict` / `cedict`，自带词典的键是文件名，换目录、装卸别的词典都不会让这份
映射错位。

输入框里**留空表示用默认名**，占位符就是那个默认名，而不是把默认名填进去：填进去
的话，「我没改过」与「我把它改成了跟默认一样」在存储里就分不开，用户也没有一个明确
的「恢复默认」动作可做。清空即恢复。

一个已知的别扭：默认状态下会出现「简明英汉字典」与「简明英汉字典增强版」并排——
因为随程序分发的 `ecdict.db` 与那本示例 MDX **本就同源**（都是 ECDICT）。这是实情
不是命名事故；改名正是为这种情形准备的出口。

## 与术语表的关系

术语表此前禁止「英汉词典 / 汉英词典」这个组合，理由是「本项目只有一个词典」。那条
的前提已经变了：页签按来源分之后，界面上确实存在多个来源，而用户必须能分辨它们。
禁令的**本意**仍然成立——不要让人以为装了两个不同的产品——故设置页里那两行仍叫
「词库」（`英汉 · ecdict.db`），页签上用的是词典各自的名字。

## 后果

- `card_in_tab(&Card, usize)` → `entry_in_tab(&Entry, &TabKey)` + `filter_cards`。
- `UserEntry` 多一个 `source_key`（文件名），与 `source`（显示名）分开。
- `UserDictionary` 把「本名」与「别名」分开存，不是就地改掉本名：用户清空输入框的
  意思是恢复默认，而就地改掉之后本名就找不回来了，只能重开一次文件去读——那让一个
  纯界面动作变成一次磁盘操作。
- 页签集合变了才重建标签条（`tabs_rev`），查询只改各页签的 `Signal<bool>`。
- 字形库**没有**页签也没有改名框：它不出词条（ADR-0013），给它一个页签点进去永远
  是空的。
