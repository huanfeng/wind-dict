# 普通话读音与字级取大陆标准来源

字形层增加两项**大陆标准**数据：普通话读音（带调号、多音齐全）取自 Unihan 的
`kXHC1983`，《通用规范汉字表》字级取自国务院 国发〔2013〕23 号文件。二者都不引入新
的许可约束。

## 读音为什么不用 `kMandarin`

ADR-0013 里写过「`kMandarin` 每字只给一个音，多音字上不如 CC-CEDICT」。那句话对
`kMandarin` 成立，但**作为对 Unihan 的判断是错的**——同一个文件里另有三个字段正好补上
它的短板，且全是大陆来源：

| 字段 | 来源 | 覆盖 | `行` |
|---|---|---|---|
| `kMandarin` | —— | 44,348 | `xíng` |
| `kTGHZ2013` | 《通用规范汉字字典》(2013) | 8,105 | `háng héng xíng` |
| `kXHC1983` | 《现代汉语词典》(1983) | 11,072 | `háng hàng héng xíng` |
| `kHanyuPinlu` | 《現代漢語頻率詞典》 | 3,799 | `xíng(2943) háng(218)` |

用一个字段的性质去判断整个数据集，是当初那个错误的形状。

这三个字段只是**拼音与页码索引**，不含释义，故不触及这些辞书本身的版权。

## 为什么取 1983 年的 `kXHC1983` 而非 2013 年的 `kTGHZ2013`

按「标准新旧」该选后者。选前者的理由不在数据，在**界面自洽**：

`kTGHZ2013` 对 `语` 只给 `yǔ`，而 CC-CEDICT 在同一张卡片下列着 `[yu3]` 与 `[yu4]`
两条词条。字形行的读音一旦**少于**下面列出的词条，卡片就在自相矛盾——上面说这字只有
一个音，下面列着两个。

`kXHC1983` 覆盖更广（11,072 > 8,105）、逐字读音更全，与 CC-CEDICT 对得上。判据是
「同一张卡片内部不能打架」，不是「哪个标准更新」。二者都缺时退到 `kMandarin`。

## 读音的排序

按 `kHanyuPinlu` 的出现次数降序。这不是可有可无的润色：源字段是按原字典**页码**排的，
即按拼音字母序，与常用度无关——照搬会让 `行` 以 `háng` 打头（字母序），而实际语料里
`xíng` 出现 2943 次、`háng` 只有 218 次。

频次表只覆盖 3,799 字，故仅作排序依据、不作读音来源；没有频次时退而把 `kMandarin`
标记的「最常用读音」提到最前。

顺带记一个反直觉但正确的结果：`长` 排成 `zhǎng cháng`。频率词典给的是
`zhǎng(1879) cháng(1179)`，`kMandarin` 也标 `zhǎng`，两个独立来源一致。看着别扭不是
排错了。

## 字级为什么可以自由使用

《通用规范汉字表》是国务院 **国发〔2013〕23 号**文件，属《著作权法》第五条所指
「国家机关的……行政性质的文件」，**不适用著作权法**。

这一点与承载它的仓库挂什么许可**无关**：没有人能对政府规范性文件主张权利，仓库作者
也不能。这与 ADR-0013 里拒绝 chinese-xinhua 的判据是同一条的两面——那次是「作者对
自己没有的东西授权，不产生效力」，这次是「内容本就不受版权保护，仓库授不授权都一样」。

分级数据实测为 3500 / 3000 / 1605 = 8105，与官方数字分毫不差；建库时 `kTGHZ2013`
的覆盖也恰好是 8,105，两个独立来源互为佐证。

## 为什么不接在线接口

调研过大陆侧的在线查询源，结论是**没有干净可用的**：

- 聚合数据 / 天聚 / 极速数据的「新华字典 API」要密钥、免费额度 100 次/天（对词典工具
  等于不可用），且服务的仍是《新华字典》内容，上游版权问题原样存在。
- 百度汉语、汉典（zdic）没有官方 API。
- 百度 / 腾讯翻译 API 额度充足，但按 ADR-0008 它们是**译源**不是词典。

而上述数据全都能离线拿到。ADR-0002 拒绝自动兜底的三条理由（配额、隐私、可降级）在这里
指向同一个结论：一个常驻后台、热键唤起的工具，把用户敲进输入框的东西发往第三方，
换回来的是每天 100 次额度——不划算。

（台湾侧另有一批可用源：萌典 `/uni/` 无需密钥、结构化、CC BY-ND 允许商用，且在线原样
显示不触碰改编条款。但它是繁體 + 台灣國語读音，与本项目「词头恒为简体」「普通话」的
定位不符，故不取。留此记录以免日后重复调研。）

## 后果

- `Glyph` 增加 `readings: Vec<String>` 与 `tier: Option<CharTier>`。
- 字形行变为「读音　部首 · 部外 N 画 · 共 N 画　字级徽章」。读音不弱化（整行里只有它
  是用户念得出来的），字级做成徽章而非行内文字——与英文词的考纲徽章同一套语言。
- 一级字用强调色，二三级用弱化色：3500 个常用字是这套分级里唯一对普通读者有意义的那档。
- 建库多一个**可选**的第三参数（字级表目录）。缺了照建，`tier` 全为 NULL。
- 实测 102,998 字中 44,357 字有读音、8,105 字有字级；库从 3.7MB 增至 4.0MB。
