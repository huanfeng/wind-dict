wind-dict PC 端 UI 重新设计决策稿

同一词典场景下的四套 Native 风格方向：布局、密度、阅读感与唤起方式各自拉开。

01 效率工作台 最接近当前实现：左侧历史/收藏、主区查询与结果、右侧查询源和备注，适合直接作为 MVP 主窗口。
02 阅读纸感 把结果当“词典书页”处理，正文更舒展，适合长释义阅读和收藏整理，但信息密度更低。
03 热键速查 面向 Ctrl+Alt+D 唤起后的即时查询，窗口更小、动作更少，适合作为未来独立速查模式。
04 深色专业 高密度、低亮度、查询源状态更显性，适合重度用户；可作为主窗口的深色皮肤方向。

建议决策路径

主窗口优先从“效率工作台”落地，因为它最贴合当前代码结构：固定侧栏、查询框、候选浮层、结果区、设置入口都能直接映射。视觉皮肤可以吸收“阅读纸感”和“深色专业”的色彩与排版，而“热键速查”更适合等主窗口稳定后做第二窗口形态。

实现注意

Native 版保持 920×620 的默认窗口与 720×480 的下限时，侧栏应支持收起；候选浮层继续覆盖结果而不推走正文；“收藏”只表达书签语义，不改名为生词本。
